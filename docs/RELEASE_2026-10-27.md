## 发布准备中的改进

- 新增英文和中文 README，明确全篇版本、结果、外部前提、空间模型、构建和审计命令。
- 新增准确的18页稿编号表，避免把旧7页稿及独立稿的编号混用。
- 将文档中的源码绝对路径链接改为可在 GitHub 使用的相对链接。
- 审计脚本现在传播构建失败；命中禁用项、未知公理或缺失声明均返回失败。
- Vendor SHA-256 清单直接对照原提交生成；默认检查不再要求本机兄弟仓库，仍可选择
  另外对照原 Git 提交。
- 冻结检查默认比较 `HEAD`，发现声明变化返回失败；历史合法加强不再因旧默认基准被误报。
- 未擅自赋予项目或 vendored 源码新的许可证。
